# Тэмдэглэл — Өдрийн дэвтэр

Монгол хэлэнд зориулсан өдрийн дэвтэр вэб апп.

## Боломжууд

- 📝 Rich текст редактор — зураг, хүснэгт, эмодзи, таг
- ☁️ Үүлэн хадгалалт (Supabase) — хаа ч нэвтэрвэл тэмдэглэлүүд чинь харагдана
- 👤 Бүртгэл/нэвтрэх (Supabase Auth) — зөвхөн өөрийн тэмдэглэлийг харна (RLS)
- 🎨 10 өнгөний theme, 38 фонт, 4 фон зураг
- 📊 Статистик: нийт тэмдэглэл, үг, бичсэн өдрийн дараалал
- 📅 Календар харагдац
- 🔒 Апп түгжээ (нууц үг)
- 💾 Экспорт/импорт (JSON)
- 📱 Responsive — гар утас, таблет

## Технологи

- Pure HTML/CSS/JS — build шаардлагагүй
- [Supabase](https://supabase.com) — Auth + Postgres хадгалалт
- Deploy: [Vercel](https://vercel.com)

## Локал ажиллуулах

```bash
npm start        # http://127.0.0.1:4191
# эсвэл
npx serve .      # статик сервер
```

## Бүртгэл

Вэб формоор шууд бүртгүүлдэг — имэйл баталгаажуулалт шаарддаггүй.
Агуулга нь зөвхөн нэвтэрсэн хэрэглэгчид харагдана.

## Бүтэц

```
index.html   — UI
app.js       — апп логик
style.css    — загвар
config.js    — Supabase тохиргоо
vendor/      — Supabase клиент
supabase/    — өгөгдлийн сангийн схем (SQL)
server.js    — локал дев сервер
```
